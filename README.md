# tracker_books
Aplicacion web para el seguimiento a la lectura de libros.

✨  **QUÉ INCLUYE**

📊  DASHBOARD
    KPIs en tiempo real: libros leídos, páginas totales, % de tu
    meta anual. Gráfico mensual de libros leídos y desglose por
    formato (físico, digital, audiolibro).

📖  BOOK LOG
    Registra cada libro con: título, autor, portada, saga, género,
    formato, páginas, estado, rating y notas. Barra de progreso
    visual que se actualiza con las páginas leídas.

🖼️  BOOKSHELF
    Estantería visual con las portadas de tus libros leídos y en
    curso. Se actualiza automáticamente.

🏆  RETOS Y BINGO
    Define tus retos anuales con barra de progreso. Bingo de
    lectura 5×5 completamente personalizable: edita las 25 casillas
    con tus propios retos.

⚙️  AJUSTES
    Tu nombre en el saludo personalizado. Meta anual configurable.
    Modo claro / oscuro. 5 paletas aesthetic. Bilingüe ES/EN.

🎨  **¿POR QUÉ TE VA A ENCANTAR?**

✅  Sin instalaciones ni registros.
✅  Sin suscripciones ni cuentas.
✅  5 paletas de colores.
✅  Modo oscuro y claro con un clic.
✅  Funciona 100% offline (tras la primera carga).
✅  Exporta e importa en JSON para backup.
✅  Tú controlas tus datos.

❓  **PREGUNTAS FRECUENTES**

▸ ¿Funciona en el móvil?
  Sí, se abre perfectamente en el navegador del móvil. Para uso
  cómodo, guárdalo en la pantalla de inicio.

▸ ¿Necesito Excel o Google Sheets?
  No. Es un archivo HTML independiente. Solo tu navegador.

▸ ¿Pierdo mis datos si cierro el navegador?
  No. Se guardan automáticamente. Solo se pierden si borras los
  datos del navegador o el caché.

▸ ¿Puedo usarlo en varios dispositivos?
  Sí, mediante la función Exportar/Importar. Exporta el JSON en
  uno y lo importas en el otro.
